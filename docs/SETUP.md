# Руководство по установке и запуску

Следуйте этой инструкции, чтобы развернуть проект локально для разработки.

## Предварительные требования

*   [Node.js](https://nodejs.org/) версии 18 или выше.
*   Менеджер пакетов `npm`, `yarn`, `pnpm` или `bun`.
*   Аккаунт [Supabase](https://supabase.com/) для базы данных.

## Установка

1.  **Клонируйте репозиторий:**

    ```bash
    git clone <repository-url>
    cd fairshare-tma
    ```

2.  **Установите зависимости:**

    ```bash
    npm install
    # или
    yarn install
    ```

3.  **Настройка окружения:**

    Создайте файл `.env.local` в корне проекта и добавьте следующие переменные (их можно найти в настройках вашего проекта Supabase):

    ```env
    NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
    NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
    ```

4.  **Настройка базы данных:**

    Выполните SQL-скрипты из файлов `supabase_schema.sql` и `supabase_migration_comments.sql` в SQL-редакторе панели управления Supabase, чтобы создать необходимые таблицы и политики безопасности.

## Запуск в режиме разработки

Запустите сервер разработки:

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в вашем браузере.

> Примечание: Для полноценного тестирования функциональности Telegram Web App может потребоваться использование туннелирования (например, ngrok) или прямая проверка в Telegram через тестового бота.

## Сборка для продакшена

Для создания оптимизированной сборки выполните:

```bash
npm run build
```

Затем запустите приложение:

```bash
npm start
```

## Деплой

Проект оптимизирован для деплоя на платформу [Vercel](https://vercel.com/new). Просто подключите ваш репозиторий GitHub, и Vercel автоматически настроит сборку. Не забудьте добавить переменные окружения в настройках проекта на Vercel.

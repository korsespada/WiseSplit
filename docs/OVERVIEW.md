# Обзор проекта FairShare TMA

FairShare TMA — это мини-приложение для Telegram, созданное по аналогии со Splitwise. Оно позволяет пользователям удобно делить расходы в группах, отслеживать долги и управлять общим бюджетом прямо внутри мессенджера.

## Основные возможности

*   **Управление группами**: Создание групп для поездок, совместного проживания или мероприятий.
*   **Учет расходов**: Добавление трат с указанием плательщика и участников, между которыми делится сумма.
*   **Детализация**: Просмотр подробностей по каждой трате.
*   **Комментарии**: Обсуждение конкретных трат внутри приложения.
*   **Баланс**: Просмотр текущего баланса и задолженностей (в разработке).
*   **Интеграция с Telegram**: Авторизация и работа через Telegram Web App.

## Технологический стек

Проект построен на современном стеке технологий, обеспечивающем высокую производительность и удобство разработки:

*   **Frontend**: [Next.js 16](https://nextjs.org/) (App Router) — фреймворк React для серверного рендеринга и статической генерации.
*   **Language**: [TypeScript](https://www.typescriptlang.org/) — типизированный JavaScript для надежности кода.
*   **Styling**: [Tailwind CSS 4](https://tailwindcss.com/) — утилитарный CSS-фреймворк для быстрой стилизации.
*   **State Management**: [Zustand](https://github.com/pmndrs/zustand) — легкая и быстрая библиотека для управления состоянием.
*   **Database**: [Supabase](https://supabase.com/) — открытая альтернатива Firebase (PostgreSQL).
*   **UI Components**: [Radix UI](https://www.radix-ui.com/) / [Shadcn UI](https://ui.shadcn.com/) — доступные и кастомизируемые компоненты.
*   **Icons**: [Lucide React](https://lucide.dev/) — красивая библиотека иконок.

## Структура проекта

*   `app/` — Страницы и макеты приложения (Next.js App Router).
*   `components/` — Переиспользуемые UI компоненты.
    *   `ui/` — Базовые компоненты интерфейса (кнопки, инпуты и т.д.).
*   `store/` — Глобальное состояние приложения (Zustand).
*   `lib/` — Утилиты и конфигурация (например, клиент Supabase).
*   `types/` — Определения типов TypeScript.
*   `public/` — Статические файлы.

# Документация компонентов

## Ключевые компоненты (`components/`)

### `Dashboard.tsx`
*   **Назначение**: Главный экран приложения.
*   **Функциональность**:
    *   Отображает список групп пользователя (компонент `GroupList`), если группа не выбрана.
    *   Отображает список расходов и действий, если группа выбрана.
    *   Кнопка "Back" для возврата к списку групп.
    *   Кнопка "Add Expense" для создания нового расхода.

### `GroupList.tsx`
*   **Назначение**: Список карточек групп.
*   **Props**:
    *   `groups`: Массив объектов `Group`.
    *   `onSelectGroup(group: Group)`: Коллбэк при нажатии на группу.
*   **Использование**: Внутри `Dashboard` для навигации.

### `CreateGroup.tsx`
*   **Назначение**: Форма создания новой группы.
*   **Функциональность**:
    *   Ввод названия группы.
    *   Кнопка создания (вызывает Supabase insert).
    *   Автоматическое добавление создателя в участники группы.

### `AddExpenseDialog.tsx`
*   **Назначение**: Диалоговое окно (модалка) для добавления нового расхода.
*   **Функциональность**:
    *   Выбор плательщика (из участников группы).
    *   Ввод описания и суммы.
    *   Выбор способа разделения счета (поровну, по долям - в разработке).
    *   Список участников для выбора, на кого делится счет.
    *   Отправка данных через `addExpense` из стора.

### `ExpenseDetailsDialog.tsx`
*   **Назначение**: Просмотр детальной информации о расходе.
*   **Props**:
    *   `expense`: Объект `Expense` для отображения.
    *   `isOpen`: Булево значение для управления видимостью.
    *   `onClose`: Функция закрытия диалога.
*   **Функциональность**:
    *   Показывает, кто заплатил и сколько.
    *   Показывает список должников по этому чеку (сплиты).
    *   Интегрирует блок комментариев (загрузка и добавление).

### `AppProvider.tsx`
*   **Назначение**: Обертка для инициализации приложения.
*   **Функциональность**:
    *   Инициализация Telegram Web App SDK.
    *   Установка начальной темы оформления.
    *   Проверка/создание пользователя в БД при первом входе.

## UI Компоненты (`components/ui/`)

Используются базовые компоненты из библиотеки Shadcn UI (Radix UI + Tailwind):
*   `Button`: Кнопки различных вариантов (default, outline, ghost).
*   `Dialog`: Модальные окна.
*   `Input`: Поля ввода.
*   `Card`: Контейнеры для контента (используются в списках).
*   `Avatar`: Аватарки пользователей.
